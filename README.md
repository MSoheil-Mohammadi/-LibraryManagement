# سامانه مدیریت کتابخانه

یک سامانه ساده مدیریت کتابخانه با استفاده از زبان برنامه‌نویسی Java Core و رابط کاربری کنسولی.

این پروژه با هدف پیاده‌سازی مفاهیم برنامه‌نویسی شیءگرا (OOP)، تفکیک مسئولیت‌ها، اعتبارسنجی ورودی‌ها، مدیریت خطاها و استفاده از مجموعه‌های داده‌ای جاوا توسعه داده شده است.

## قابلیت‌های پروژه

- **ثبت کتاب جدید:** ثبت عنوان، نام نویسنده، شماره استاندارد کتاب (ISBN) و سال انتشار.
- **مشاهده کتاب‌ها:** نمایش فهرست کتاب‌های ثبت‌شده به همراه اطلاعات آن‌ها.
- **ویرایش اطلاعات کتاب:** امکان ویرایش عنوان، نویسنده و سال انتشار کتاب. شماره ISBN پس از ثبت قابل تغییر نیست.
- **حذف کتاب:** حذف کتاب در صورتی که در حال حاضر به امانت داده نشده باشد.
- **امانت دادن کتاب:** ثبت امانت کتاب بر اساس شماره ISBN و نام امانت‌گیرنده، همراه با ثبت تاریخ امانت.
- **بازگرداندن کتاب:** ثبت تاریخ بازگشت و تغییر وضعیت کتاب به موجود.
- **جستجوی کتاب:** جستجو بر اساس عنوان، نویسنده، سال انتشار و وضعیت موجود بودن.
- **اعتبارسنجی ورودی‌ها:** بررسی ورودی‌های کاربر و مدیریت عملیات نامعتبر.

## پیش‌نیازها

برای اجرا و توسعه پروژه به نرم‌افزارهای زیر نیاز است:

- کیت توسعه جاوا (JDK) نسخه ۲۵ یا بالاتر
- ابزار مدیریت و ساخت پروژه Apache Maven نسخه ۳.۱۰ یا بالاتر

## نحوه اجرای پروژه

### ۱. دریافت پروژه

ابتدا مخزن پروژه را دریافت کنید:

```bash
git clone https://github.com/MSoheil-Mohammadi/-LibraryManagement.git
```

### ۲. ورود به پوشه پروژه

```bash
cd -LibraryManagement
```

### ۳. ساخت پروژه

دستور زیر را در ترمینال اجرا کنید:

```bash
mvn clean package
```

### ۴. اجرای برنامه

پس از ساخت موفقیت‌آمیز پروژه، دستور زیر را اجرا کنید:

```bash
java -cp target/classes Main
```

همچنین می‌توانید پروژه را در محیط IntelliJ IDEA باز کرده و با اجرای کلاس `Main` برنامه را راه‌اندازی کنید.

### مسئولیت بخش‌های مختلف پروژه

- **model:** شامل کلاس‌های اصلی داده‌ای پروژه، یعنی `Book` و `Loan` است.
- **service:** منطق اصلی مدیریت کتابخانه، شامل ثبت، ویرایش، جستجو، امانت، بازگشت و حذف کتاب را پیاده‌سازی می‌کند.
- **ui:** مسئول تعامل با کاربر و دریافت ورودی‌ها از طریق کلاس `ConsoleMenu` است.
- **Main:** نقطه شروع اجرای برنامه است.

## سه تصمیم مهم در طراحی پروژه

### ۱. تفکیک مسئولیت‌ها

ساختار پروژه به سه بخش اصلی `model`، `service` و `ui` تقسیم شده است.

این تفکیک باعث می‌شود مدل داده‌ها، منطق اصلی برنامه و ارتباط با کاربر مستقل از یکدیگر باشند. در نتیجه، خوانایی، نگهداری و توسعه پروژه آسان‌تر خواهد بود.

### ۲. استفاده از حافظه برای نگهداری اطلاعات

برای ذخیره اطلاعات کتاب‌ها و سوابق امانت از مجموعه‌های داده‌ای جاوا (`ArrayList`) استفاده شده است.

این روش با توجه به محدوده تمرین، پیاده‌سازی را ساده نگه می‌دارد و نیازی به راه‌اندازی و پیکربندی پایگاه داده ندارد.

### ۳. استفاده از ISBN به‌عنوان شناسه کتاب

شماره استاندارد کتاب (ISBN) برای شناسایی کتاب‌ها در عملیات مختلف استفاده می‌شود.

این مقدار پس از ثبت کتاب قابل ویرایش نیست تا شناسایی کتاب در عملیات امانت، بازگشت، ویرایش و حذف با مشکل مواجه نشود.

## محدودیت‌ها و توسعه‌های آینده

در صورت اختصاص زمان بیشتر، قابلیت‌های زیر می‌توانند به پروژه اضافه یا در آن بهبود داده شوند:

- اتصال به پایگاه داده برای نگهداری دائمی اطلاعات کتاب‌ها و سوابق امانت.
- نوشتن تست‌های خودکار (Unit Test) برای بررسی عملکرد بخش‌های اصلی برنامه.
- افزودن قابلیت مرتب‌سازی و صفحه‌بندی برای مدیریت تعداد زیادی کتاب.
- بهبود رابط کاربری و ارائه پیام‌های خطای دقیق‌تر.
- پشتیبانی از چند کاربر هم‌زمان و مدیریت پیشرفته‌تر فرایند امانت.

## نکات مهم

- این برنامه از رابط کاربری کنسولی استفاده می‌کند.
- اطلاعات کتاب‌ها و سوابق امانت در حافظه نگهداری می‌شوند و با بسته شدن برنامه از بین می‌روند.
- برای اجرای پروژه نیازی به فریم‌ورک‌های جانبی جاوا یا پایگاه داده نیست.
